# Gatherly Entry and Event Workspace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a focused Gatherly prompt page that creates a persistent Convex event and opens a responsive event workspace at a unique static-export-compatible URL.

**Architecture:** The statically exported Next.js app remains a client-rendered shell backed by Convex queries and mutations. `/` creates an event, then navigates to `/event?id=<eventId>`; the event route reads the query parameter behind a Suspense boundary and subscribes to the saved event. The first slice persists only events and deterministic, visibly labeled demo activity so the UI is honest before Firecrawl, OpenAI, and AgentMail are connected.

**Tech Stack:** Next.js 16.3.5 App Router, React 19.2.8, TypeScript, Tailwind CSS 4, shadcn/ui, Convex, Vitest, convex-test, Bun.

**Spec:** `docs/superpowers/specs/2026-09-21-gatherly-entry-and-event-workspace-design.md`

## Global Constraints

- Preserve `output: "export"` and `distDir: "dist"`; the production artifact remains deployable through Convex static hosting.
- Use `/event?id=<convex-event-id>`; do not add a runtime dynamic route.
- Use Manrope and the existing bone, paper, stone, ink, graphite, ashen, chalk, and clay tokens.
- Reuse the installed shadcn primitives and Lucide icons; add no production UI dependency.
- No gradient, glass effect, decorative blob, fake metric, testimonial, pricing section, or long-form marketing content.
- No outbound email is represented as sent without an explicit organizer action.
- Demo activity must be visibly labeled as demo behavior.
- Do not store real organizer, venue-email, or reply data until authentication and event authorization exist.
- Run JavaScript and package commands with Bun.

## Review Focus

- Whitespace-only or extremely long briefs: reject empty input, preserve meaningful Unicode, and cap the stored brief at 4,000 characters with a clear client message.
- Repeated submission or a lost mutation response: the same request key must resolve to one event rather than create duplicates.
- Missing, empty, malformed, or unknown `id` query parameters: show a recovery state without throwing or creating a replacement event.
- Convex configuration missing at build or runtime: fail with an actionable message instead of rendering a broken form.
- Narrow screens and keyboard use: preserve logical reading order, visible focus, labeled controls, and textual activity status.

```ts
import { defineSchema, defineTable } from "convex/server";
import { v } from "convex/values";

export const activityState = v.union(
  v.literal("queued"),
  v.literal("active"),
  v.literal("completed"),
  v.literal("failed"),
  v.literal("approval_required"),
);

export const activity = v.object({
  key: v.string(),
  label: v.string(),
  description: v.string(),
  state: activityState,
});

export default defineSchema({
  events: defineTable({
    brief: v.string(),
    title: v.string(),
    requestKey: v.string(),
    status: v.union(
      v.literal("researching"),
      v.literal("review_ready"),
      v.literal("failed"),
    ),
    isDemo: v.boolean(),
    activities: v.array(activity),
  }).index("by_request_key", ["requestKey"]),
});
```

Create `convex/events.ts` with an idempotent mutation and safe string lookup:

```ts
import { ConvexError, v } from "convex/values";
import { mutation, query } from "./_generated/server";

const initialActivities = [
  {
    key: "brief",
    label: "Understanding the brief",
    description: "Gatherly extracted the core event requirements.",
    state: "completed" as const,
  },
  {
    key: "search",
    label: "Searching venue sources",
    description: "Demo activity — live venue research is not connected yet.",
    state: "active" as const,
  },
  {
    key: "capacity",
    label: "Checking capacity and requirements",
    description: "Queued until venue sources are available.",
    state: "queued" as const,
  },
  {
    key: "contacts",
    label: "Finding public contact routes",
    description: "Queued until candidate venues are identified.",
    state: "queued" as const,
  },
  {
    key: "shortlist",
    label: "Building the shortlist",
    description: "Queued until venue evidence is collected.",
    state: "queued" as const,
  },
  {
    key: "outreach",
    label: "Drafting outreach",
    description: "No email will be sent without organizer approval.",
    state: "queued" as const,
  },
];

export const create = mutation({
  args: { brief: v.string(), requestKey: v.string() },
  handler: async (ctx, { brief: rawBrief, requestKey }) => {
    const existing = await ctx.db
      .query("events")
      .withIndex("by_request_key", (q) => q.eq("requestKey", requestKey))
      .unique();
    if (existing) return existing._id;

    const brief = rawBrief.trim();
    if (!brief) {
      throw new ConvexError("Describe the event before starting a search.");
    }
    if (brief.length > 4000) {
      throw new ConvexError("Event briefs must be 4,000 characters or fewer.");
    }

    const title = brief.length > 64 ? `${brief.slice(0, 61).trimEnd()}…` : brief;
    return ctx.db.insert("events", {
      brief,
      title,
      requestKey,
      status: "researching",
      isDemo: true,
      activities: initialActivities,
    });
  },
});

export const get = query({
  args: { eventId: v.string() },
  handler: async (ctx, { eventId }) => {
    const normalizedId = ctx.db.normalizeId("events", eventId);
    return normalizedId ? ctx.db.get(normalizedId) : null;
  },
});
```

```ts
export function normalizeEventBrief(value: string) {
  const brief = value.trim();
  if (!brief) return null;
  if (brief.length > 4000) {
    throw new Error("Event briefs must be 4,000 characters or fewer.");
  }
  return brief;
}

export function eventHref(eventId: string) {
  return `/event?id=${encodeURIComponent(eventId)}`;
}
```

```tsx
const EXAMPLES = [
  "A 300-person hackathon in London with overnight access and strong Wi-Fi",
  "A creative showcase for 180 guests with a stage and late-evening access",
  "A company gathering for 120 people near central London with catering",
];

const createEvent = useMutation(api.events.create);
const router = useRouter();
const requestKeyRef = useRef<string | null>(null);
const submittingRef = useRef(false);

async function handleSubmit(event: FormEvent<HTMLFormElement>) {
  event.preventDefault();
  if (submittingRef.current) return;

  try {
    const normalized = normalizeEventBrief(brief);
    if (!normalized) {
      setError("Describe the event before starting a search.");
      return;
    }

    submittingRef.current = true;
    setPending(true);
    setError(null);
    requestKeyRef.current ??= crypto.randomUUID();
    const eventId = await createEvent({
      brief: normalized,
      requestKey: requestKeyRef.current,
    });
    router.push(eventHref(eventId));
  } catch (error) {
    setError(error instanceof Error ? error.message : "Gatherly could not create this event. Try again.");
  } finally {
    submittingRef.current = false;
    setPending(false);
  }
}
```
